Karst Lab homepage replacement package

Upload these items to the ROOT of the GitHub repository:
- index.html
- styles.css
- assets/hero-art.png

The first two replace the existing files.
The assets folder should merge with the existing assets folder.

Repository:
https://github.com/karst-lab/karst-lab.github.io

After upload:
1. Click Commit changes.
2. Wait 1–2 minutes.
3. Refresh https://karst-lab.github.io
