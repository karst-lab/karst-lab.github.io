# Karst Laboratory website

This is a ready-to-upload static website for GitHub Pages.

## Upload
1. Open the karst-lab/karst-lab.github.io repository on GitHub.
2. Upload all files and the assets folder from this package.
3. In Settings -> Pages, publish from the main branch and /(root).
4. Visit https://karst-lab.github.io

The homepage is index.html. Styling is controlled by styles.css.
